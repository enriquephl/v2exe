# 写规则文件

适用于一切会被当指令载入的文件：CLAUDE.md、AGENTS.md、`.claude/rules/*.md` 及同类文件。

1. **两层。** 跨仓的姿态放上层文件。单个仓的规则留在那个仓。只对某些路径有意义的规则放 `.claude/rules/`，带 `paths:` 列表，只在碰到那些文件时加载。
2. **AGENTS.md 以索引开头。** 索引按阅读顺序说明每条规则在哪。全仓适用的规则以小节形式跟在索引后；只对某些路径适用的规则放到第 1 条指定的位置，并在索引里占一行。CLAUDE.md 只有一行：`@AGENTS.md`。
3. **「定稿，不许改」只用于用户逐字说出的约束。** 从多次被纠正中推断出的规则，写成「当前实现是 X，因为 Y」。同一点被反复纠正说明 agent 理解错了，不说明结论该冻结。
4. **已经变成规则的记忆，从记忆里删掉。** 只留一份。
5. **每个规则文件只有一份权威副本。** 文件不在 git 里时，由 hook 镜像进一个 git 仓留历史。绝不编辑镜像。
